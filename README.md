# 🤖 Telegram Pure Calculation Bot (纯净计算机器人)

一个基于 `python-telegram-bot` 开发的轻量、安全、纯净的 Telegram 数学计算机器人。支持严格的表达式过滤、异常处理，并带有**快捷复制内联按钮**。

---

## ✨ 主要特性

- **🛡️ 绝对纯净与安全**：无任何第三方灰产、广告或多余模块，完全自主掌控。
- **🧮 智能计算过滤**：只允许合法的数学表达式（数字、加减乘除、括号、小数点），自动忽略无用文本或汉字，绝不乱刷屏。
- **📋 快捷复制按钮**：每次计算出结果后，下方会自动生成一个内联按钮，点击即可快速复制或引用计算结果。
- **⚙️ 一键交互部署**：提供全自动安装脚本，支持在安装过程中交互式输入 Token。
